# data-appliance
## File Variations by Row Count, File Count, and File Size

This repository contains multiple datasets designed to test different ingestion and ETL scenarios.

### Available Datasets

- **[11_millions_updates_deletes.zip](https://github.com/user-attachments/files/29927210/11_millions_updates_deletes.zip)**
  - Large dataset (~11 million records) containing inserts, updates, and deletes for CDC and merge testing.

- **[10_ultra_one_million_files.zip](https://github.com/user-attachments/files/29927209/10_ultra_one_million_files.zip)**
  - One million small files to test high file-count ingestion performance.

- **[09_many_large_parquet_sales.zip](https://github.com/user-attachments/files/29927208/09_many_large_parquet_sales.zip)**
  - Large Parquet sales datasets for performance and partition testing.

- **[08_many_small_parquet_multiple_tables.zip](https://github.com/user-attachments/files/29927207/08_many_small_parquet_multiple_tables.zip)**
  - Multiple small Parquet files across several tables to simulate enterprise workloads.

- **[07_many_small_parquet_transaction.zip](https://github.com/user-attachments/files/29927206/07_many_small_parquet_transaction.zip)**
  - Small transactional Parquet files suitable for incremental processing tests.

- **[06_many_large_csv_emp.zip](https://github.com/user-attachments/files/29927205/06_many_large_csv_emp.zip)**
  - Large CSV employee datasets for bulk ingestion benchmarking.

- **[05_many_small_csv_multiple_tables.zip](https://github.com/user-attachments/files/29927204/05_many_small_csv_multiple_tables.zip)**
  - Multiple small CSV files across several tables for file orchestration testing.

- **[04_many_small_csv_emp.zip](https://github.com/user-attachments/files/29927203/04_many_small_csv_emp.zip)**
  - Small CSV employee dataset for basic ingestion and validation.

- **[03_many_large_json_sales.zip](https://github.com/user-attachments/files/29927202/03_many_large_json_sales.zip)**
  - Large JSON sales datasets for semi-structured data processing.

- **[02_many_small_json_multiple_tables.zip](https://github.com/user-attachments/files/29927200/02_many_small_json_multiple_tables.zip)**
  - Multiple small JSON datasets across several tables for ingestion testing.

- **[01_many_small_json_customer.zip](https://github.com/user-attachments/files/29927199/01_many_small_json_customer.zip)**
  - Small JSON customer dataset for learning and functional validation.
